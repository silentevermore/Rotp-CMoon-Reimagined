# 🌕 Absolutely reimagined CMoon addon, which adds a brand new stand, for the mod known as Ripples of the Past, that capable of controlling over the Gravity.

## ⚡ Released/Planned abilities:
- **🔃 Gravity change:** changes direction of gravity, depending on where the user looks at.
- **👊 Inversional punches:** gives or removes the inversion effect on target entity, that slowly drains it's health forever.
- **🛡️ Gravity shield:** generates gravitational shields both for stand and it's user, protecting them from any kind of damage for the short period of time.
